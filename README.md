# Katika Admin Dashboard

An admin dashboard for managing the Katika gaming platform. It covers analytics, games and tournaments, finance, users, reports, and settings.

## Pages

- **Dashboard:** overview with stat cards, revenue and category charts, popular games, and recent activity
- **Analytics:** analytics charts and the team members list
- **Games:** featured games, live matches, tournaments, and tournament creation
- **Finance:** wallet income, financial stats, and a transaction table
- **Users**, **Reports**, and **Settings**
- **Logout**

## Tech stack

- Next.js (App Router) and React
- Recharts for charts
- Lucide icons

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm run start` | Serve the production build |
